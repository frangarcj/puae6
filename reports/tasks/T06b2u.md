# T06b2u — dump CPU seguro sin debugger

0016 guarda el decode de prefetch, el recorrido prevpc y Next PC con DEBUGGER.
Sin esa feature el dump conserva D/A/SR/pilas/latch y emite una sola advertencia
de disassembly no disponible. Evita tanto w indeterminado como el bucle donde
m68k_disasm no avanzaba prevpc. Resuelve el pendiente de T06b2s.

Probe real ampliado en test_cpu_prefetch: compatible on/off, nextpc nulo/no nulo,
prevpc=PC-2, datos de registros/latch, ningun fetch y nextpc intacto. O0/O2 con
ASan/UBSan y -Werror=uninitialized PASS. CMake CPU Debug/Release PASS; 40
regresiones CPU status/diagnostics/plan PASS; GEN01 39 outputs reproducibles;
HOST01 191 archivos/766 includes/332 identificadores. Luna audito el defecto;
se eligio excluir decode no disponible para no exigir inicializacion de tablas
al diagnosticar un fallo temprano. No se amplia soporte de debugger.

Build completo medido en build/t06b2t-engine-failures.log: 14 unidades pendientes.
T06b2v conserva esa puerta; este fix no prueba enlace ni arranque.
