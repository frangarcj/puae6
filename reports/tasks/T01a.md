# T01a: snapshot WinUAE comprobable

T01 se divide por tamano en T01a (WinUAE/importador) y T01b (referencias,
captura local y licencias). T01 conserva sus checks y aceptacion originales;
T02 sigue dependiendo de T01 completa. No se ha iniciado el port del motor.

Comandos disponibles desde la raiz:

```sh
python3 tools/import_sources.py fetch
python3 tools/import_sources.py import
python3 tools/import_sources.py verify
python3 -m unittest discover -s tests -p 'test_*.py'
```

Solo `fetch` accede a la red, por los pins del lock; usa la cache ignorada
`build/source-cache/winuae.git`. `import` extrae blobs Git sin aplicar
export-ignore/subst y comprueba bytes, rutas y modos antes de publicar el arbol.
Rechaza submodulos no seleccionados y rutas/tipos no soportados, sin omitirlos.
`verify` funciona sin Git ni red contra el manifiesto versionado y el lock.
Un arbol alterado no se repara ni se sobrescribe. Si se interrumpe antes de
escribir el manifiesto, reimportar solo lo recupera tras comparar el arbol
completo con los blobs fijados.

SRC01 limitado a WinUAE: 1134 archivos del tag 6030, objeto anotado y commit
peeled coincidentes con el lock. Reimportacion en un directorio temporal nuevo
con cache local: manifiesto identico byte a byte. Verificacion de esa copia
con subprocess deshabilitado: pasa. Tests con repositorio Git sintetico cubren
alteracion/borrado/extra/modo/symlink, pins incorrectos, gitlinks, preservacion
de cambios, rutas externas y recuperacion tras interrupcion. 44 tests pasan
(35 del inspector y 9 del importador). No son pruebas del emulador.
