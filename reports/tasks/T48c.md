# T48c: preparacion independiente de peliculas cortas y largas

La seleccion `-k '*.MoviePlaybackTests.*'` prepara solamente dos peliculas de
720 unidades. La clase `LongMoviePlaybackTests` conserva el escenario de 10000
unidades y sus dos reproducciones simultaneas en procesos nuevos. La suite
completa sigue descubriendo seis pruebas de comportamiento.

## Comprobaciones

- `python3 -m unittest tests.test_movie_setup -v`: cinco pruebas pasan; harness
  simulado, sin ejecucion de emulador. Comprueban unidades preparadas, seleccion
  real del loader, discovery y limpieza tras fallo en ambas clases.
- Comparacion AST contra HEAD: los seis cuerpos de pruebas conservan exactamente
  sus assertions y operaciones. Solo se separan la preparacion y la limpieza.
- `python3 -m unittest tests.test_build_support tests.codegen.test_cache
  tests.test_plan`: 64 pruebas pasan. Son regresiones de infraestructura.
- `python3 -m unittest discover -s tests/bizhawk-movies -p test_movie_playback.py
  -k test_a_movie_that_ends_before_the_core_does_is_an_error`: una prueba pasa
  en Waterbox real, sin SKIP, en 60,190 s. Incluye 1,51 s de compilacion C#.
- `git diff --check` y `python3 tools/plan.py validate`: pasan.

## Medicion

Antes, seleccionar un caso corto preparaba 11440 unidades (10000 + 720 + 720).
Ahora prepara 1440 (720 + 720). El conteo se comprueba con el harness simulado;
no representa un tiempo medido ni certifica el motor.

Medicion real del 2026-10-03, en macOS 26.7 ARM64, Python 3.14.7 y .NET 10.0.400:

| Preparacion | Unidades | Tiempo total |
| --- | --- | --- |
| Clase de HEAD, antes de separar | 11440 | 327,924 s |
| Clase corta actual | 1440 | 39,025 s |

Las dos preparaciones corrieron en orden, dentro del mismo proceso Python.
La clase anterior se cargo desde `git show HEAD:tests/bizhawk-movies/test_movie_playback.py`.
Se llamo a `setUpClass()` y se midio con `time.monotonic()`.
Se limpio cada harness despues de medirlo.

La primera medida incluye 44,14 s de compilacion C#.
La segunda usa el build ya preparado.
Estos tiempos no son medidas aisladas del motor.
No permiten atribuir toda la diferencia a la separacion de fixtures.
El conteo demuestra que un caso corto evita 10000 unidades de preparacion.
No se ejecuto la suite larga completa para obtener estas medidas.

Una seleccion corta no sustituye WB02 ni la puerta de T22.
