# T05b: configuracion, texto e integracion de headers

Subfamilias T05b1-b3 completadas, conservando la puerta conjunta.

- `sysconfig.h` selecciona CPUEMU_13, deriva los anchos reales del compilador
  y usa storage atomic signed32. Rechaza cada feature_off del manifiesto incluso
  definida como cero, UAE_MINI/SUPPORT_THREADS y ABI fuera de LP64/LLP64.
- `tchar.h` usa bytes UTF-8. La copia con longitud/capacidad explicitas valida
  escalares, rechaza NUL interno y errores sin escritura parcial, y admite
  solapamiento sin depender del locale. No agrega wrappers Win32.
- El parche 0003 cambia tres condiciones de `include/sysdeps.h`: reconoce
  __aarch64__ y evita las ramas Win32 de servicios/calling convention cuando
  P6_PORTABLE esta activo. `target.h` aporta solo identidad/constantes.

Comprobaciones ejecutadas:

```sh
python3 -m unittest discover -s tests -v
python3 tools/check_host_surface.py audit
python3 tools/import_sources.py verify --all
python3 tools/check.py --check HARNESS01 --task T04
python3 tools/generate_cpu.py --check
python3 tools/generate_cpu.py
python3 tools/plan.py validate
```

101 tests pasan. Los probes C11/C++17 con sysdeps real, TCHAR y maccess ejecutan
en macOS ARM64 con ASan/UBSan; los depfiles verifican los headers portables y
la ausencia de od-win32. Los probes ABI LP64 Linux ARM64 y LLP64 Windows x64 son
compilacion cruzada freestanding, NO ejecucion de esos hosts ni build completo.
Los casos negativos rechazan UTF-8 malformado, buffers insuficientes, macros
wide-TCHAR y features excluidas. HARNESS01 conserva su scope de infraestructura.

GEN01 produce 39 salidas identicas en dos builds limpios, tambien identicas a
las anteriores al parche. Se conservaron los antiguos outputs en
build/upstream-before-t05b3 y build/generated-before-t05b3; se regeneraron las
rutas canonicas sin sobrescribir un recibo incompatible. Pristine sigue verificado.

Limites: son headers y utilidades de texto, no la implementacion completa de
servicios host. Las funciones extern, atomics, strings legacy y rechazos de
configuracion runtime necesitan conexion/comprobacion en T05c/T06/T13. No se
afirma cierre de enlace del motor, soporte Windows completo ni emulacion.
